# dev-portfolio

Dev portfolio — React, Vite, i18n (pt-BR / EN), Netlify-ready.

**Repo:** [github.com/matheusmendes720/dev-portfolio](https://github.com/matheusmendes720/dev-portfolio)

## Quick start

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Scripts

| Command         | Description        |
|-----------------|--------------------|
| `npm run dev`   | Dev server (HMR)   |
| `npm run build` | Production build   |
| `npm run preview` | Preview production build |
| `npm run lint`  | ESLint             |

## Deploy

See [DEPLOY.md](./DEPLOY.md) for CI/CD (Git → Netlify).  
Branch `versioning` is used for custom variants; `main` is the baseline.
